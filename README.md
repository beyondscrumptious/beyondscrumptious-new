# Beyond Scrumptious Website

## Quick Start

1. Install Node.js:
https://nodejs.org

2. Open terminal in this folder

3. Run:

```bash
npm install
npm run dev
```

4. Open:
http://localhost:3000

## Add Your Hero Video

Place your video here:

```bash
/public/videos/hero.mp4
```

## Deploy

Push to GitHub and import into Vercel.
